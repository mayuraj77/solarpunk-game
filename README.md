# Solarpunk game (working title)

An unnamed multiplayer solarpunk strategy game. Players run settlements in a shared, damaged valley, compete for Standing, and must restore the valley together or all fail.

- **Play the prototype:** open `prototype/solarpunk-valley.html` in a browser, or use the hosted copy at https://claude.ai/artifact/NRyh2sdGx7oYueEM6GNCWr
- **Design summary:** `docs/design-summary.md`
- **Design log (living record):** https://claude.ai/artifact/V2tSHj7XhE1Xf6DX6thEWJ
